# 自学

基于csdiy提到的[好处](https://csdiy.wiki/#_3)与[坏处](https://csdiy.wiki/#_4)，这里想再啰嗦两句。
## 自学的好处
### 学习课外知识
我不希望你寄托于课内的知识，认为其可以扫清未来的一切障碍。但事实是，在现阶段，SQA课程所教我的内容，与国内外大学生所学的内容有很大出入。也许真正步入工作后，发现用的东西和所学内容大相径庭。并且，计算机作为当下比较热门和具有前沿的专业而言，与时俱进也十分关键。但是SQA很难根据当下做出适当调整......

因此，我希望你可以尝试开始学习课外知识，无论是你感兴趣的，还是跟课内内容相关的、无关的，还是面向就业的内容，这些都是out of lecture的自学。如果你在以后的学习或工作中用上了，它将极大的减轻你的压力并很快赶上进度；如果没有用上，作为计算机学生要学会与时俱进。别灰心，接下来才是自学的真正受益之处。

### 培养自学能力
作为SQA学生，我们不得不面对的是最后2年的出国学习（例如：1年英本+1年英硕）。习惯了国内学习节奏和方法的我们一旦进入国外，可能很难在短时间之内融入到新的环境中，课上听着老师“天花乱坠”，课后ppt的内容一点也看不懂，那么有什么好的方法吗？

有的兄弟，有的。

尝试去看看国外大学的网课吧。这些内容不仅面向全球的知识爱好者，并且也会提供给本校的学生学习（你与他们无异）。因此，你相当于拿到了当地大学的体验卡，沉浸在在他们的环境中听课、学习、写作业等等。

## 自学的坏处
自学也不是多多益善，要兼顾课内学业的同时进行。我知道大多数人对SQA的pro<del>破</del>大纲有争议，但是最后考试依旧以SQA大纲为准。
